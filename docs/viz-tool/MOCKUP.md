## Animation States

### Initial Load

```
Frame 1 (0ms):
  All nodes at center, opacity: 0

Frame 2 (200ms):
  Nodes fade in, opacity: 0.3
  Begin force simulation

Frame 3 (500ms):
  Nodes moving to columns
  Opacity: 0.7

Frame 4 (1000ms):
  Nodes settled in position
  Opacity: 1.0
  Edges fade in
```
