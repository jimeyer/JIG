# Align Command

A single `jigy align` command runs the full workflow: rebuild all graphs, validate, and display summary.

**Usage:**
```bash
jigy align
```

**Behavior:**
1. Rebuild all graphs in order: impl → verify → intent
2. Validate all artifacts (intent, bricks)
3. Display summary with counts and alignment status
4. Exit 0 if aligned, non-zero on any failure

**Output Format:**
```
Rebuilding graphs...
  intent: 45 specs, 5 outcomes
  impl: 312 functions
  verify: 89 tests

Validating...
  intent: OK
  bricks: OK (12 bricks, 3 layers)

Summary:
  Specs: 45 total (42 implemented, 38 verified)
  Status: ALIGNED
```

**Rationale:** Single command for the common "sync everything and check status" workflow. Replaces the old `jigy rebuild` which had confusing semantics.
