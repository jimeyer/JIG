# Multi-Graph Loading in Visualizer

The visualizer MUST load multiple graph types (intent, implementation, verification) simultaneously.

**Acceptance Criteria**:
- Visualizer can load intent-graph.ndjson and parse spec, outcome, and brick nodes
- Visualizer can load implementation-graph.ndjson and parse function, class, module nodes
- Both graphs can be loaded simultaneously without conflicts
- Graph type auto-detected from node types present in file
- State management supports multiple loaded graphs with distinct storage
- UI provides graph selection controls (checkboxes for intent/impl/verify)
- Auto-load attempts to fetch default graphs from `../jig/generated/` on page load
- Error handling gracefully manages missing or malformed graphs
- Console logs indicate which graphs loaded successfully

**Rationale**: Brick visualization requires joining intent graph (brick definitions) with implementation graph (code structure). Multi-graph loading is prerequisite for query-time joining per A001 §6.2.
