# Switch Between Layout Algorithms

The visualizer MUST allow switching between different layout algorithms to reveal different structural patterns.

**Acceptance Criteria**:
- Layout dropdown with options: Hierarchical (Rows), Hierarchical (Columns), Force-directed, Circular, Grid
- Hierarchical (Rows) layout: top-down tree structure showing containment
- Hierarchical (Columns) layout: left-to-right tree structure, modules on left, descending right
- Force-directed layout: organic clustering based on connections
- Circular layout: nodes arranged in circle, good for seeing all connections
- Grid layout: organized rows and columns
- Selecting a layout re-layouts the graph smoothly (animated)
- Layout choice persists during session
- Re-layout preserves node selection and filter states

**Rationale**: Different layouts reveal different architectural patterns. Hierarchical layouts (rows/columns) show containment structure with different orientations, force-directed shows clustering, circular shows connectivity. The column-based hierarchical layout is particularly useful for viewing module dependency chains flowing left-to-right.
