# JSON Output Format for CI Integration

Provide structured JSON output format for all validation commands to enable CI/tooling integration.

**Acceptance Criteria**:
- Flag `--format json` available on all validate commands
- JSON output includes structured error codes (e.g., `MISSING_REQUIRED_FIELD`, `INVALID_SPEC_REFERENCE`)
- Each error has: `file`, `line`, `code`, `message`, `severity` fields
- Output includes summary: `total_errors`, `total_warnings`
- Output shows validation status: `passed` (boolean) per phase
- JSON schema is consistent across all validation commands
- JSON is valid and parseable (no syntax errors)
- Human-readable format is default (no flag required)

**Rationale**: CI systems and editor integrations need machine-parseable output. Structured error codes enable automated error handling.
