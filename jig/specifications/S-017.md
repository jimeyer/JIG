# Load NDJSON File from Filesystem

The visualizer MUST allow loading implementation graph NDJSON files from the filesystem.

**Acceptance Criteria**:
- "Load Graph" button opens file picker dialog
- Drag-and-drop NDJSON file onto page loads the graph
- On page load, attempt to load `../jig/generated/implementation-graph.ndjson` (relative path)
- If default file not found, show file picker
- Show loading spinner during file read and parsing
- Show error message if file read fails (with clear error description)
- After successful load, display graph statistics (node count, edge count, generation timestamp)

**Rationale**: Users need to load different graph files (current graph, historical graphs, graphs from different projects). File loading is the primary input mechanism.
