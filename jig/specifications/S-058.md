# Verb-First Rebuild Commands

Graph rebuilds are invoked as `jigy rebuild {target}` with verb-first structure.

**Commands:**
```bash
jigy rebuild         # Rebuild all three graphs
jigy rebuild impl    # Rebuild implementation graph only
jigy rebuild intent  # Rebuild intent graph only
jigy rebuild verify  # Rebuild verification graph only
```

**Behavior:**
- `jigy rebuild` invokes all three in order: impl → verify → intent
- Each subcommand uses auto-discovered project root (S-057)
- Output paths are canonical per A001 conventions
- No options on any rebuild command

**Output Paths:**
- `jig/generated/implementation-graph.ndjson`
- `jig/generated/verification-graph.ndjson`
- `jig/generated/intent-graph.ndjson`

**Rationale:** Verb-first is more memorable: "rebuild the impl graph" maps directly to `jigy rebuild impl`. Eliminates cognitive load of remembering `jigy impl rebuild`.
