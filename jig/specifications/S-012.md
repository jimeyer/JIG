# Search Nodes by Name/ID with Fuzzy Matching

The visualizer MUST provide fuzzy search to find nodes by name or ID.

**Acceptance Criteria**:
- Search input field accepts text queries
- Partial matches are found (e.g., "Token" finds "TokenValidator")
- Case-insensitive matching
- Results highlight matching nodes in the graph
- Results list shows matching node names/IDs
- Clicking a result selects and centers that node
- Empty search shows all nodes (no filtering)
- Search works with filtered graphs (only searches visible nodes)

**Rationale**: In graphs with 100+ nodes, visual scanning is inefficient. Search enables quick navigation to specific elements by name or ID.
