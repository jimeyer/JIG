# Filter Edges by Type with Real-Time Update

The visualizer MUST allow filtering edges by type with immediate graph updates.

**Acceptance Criteria**:
- Checkboxes provided for: Contains, Implements, Imports
- Unchecking a checkbox immediately hides all edges of that type
- Re-checking a checkbox immediately shows all edges of that type
- Filtering preserves graph layout (nodes don't jump around)
- Nodes remain visible even when their edges are hidden
- Filter state persists during session (doesn't reset on other interactions)

**Rationale**: Different edge types reveal different architectural concerns. Hiding "contains" edges reveals dependency flows. Hiding "imports" edges reveals logical structure.
