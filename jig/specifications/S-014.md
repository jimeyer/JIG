# Display Edge Metadata When Selected

The visualizer MUST display detailed edge metadata when an edge is selected.

**Acceptance Criteria**:
- Clicking an edge displays its metadata in the details panel
- For all edges: show `type`, `source` (node ID/name), `target` (node ID/name)
- For import edges: show `line` number where import occurs
- Source and target nodes are clickable links that select those nodes
- Edge type is clearly labeled (e.g., "Contains", "Implements", "Imports")
- Metadata display is formatted for readability (not raw JSON)

**Rationale**: Edges represent relationships. Developers need to understand what type of relationship exists and where it originates in source code (import line numbers).
