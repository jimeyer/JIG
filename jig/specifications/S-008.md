# Render Nodes Distinguished by Type

The visualizer MUST render nodes with visual distinctions based on their type.

**Acceptance Criteria**:
- Class nodes render as rectangles
- Function nodes render as circles or ellipses
- Module nodes render as rounded rectangles
- External module nodes render with different color/shading than internal modules
- Node labels display the node name
- Nodes with `implements` field are visually distinguished (e.g., border color)

**Rationale**: Visual distinction enables quick recognition of node types without reading labels. Supports pattern recognition and architectural understanding.
