# Layer Field Presence Validation

All bricks in bricks.yaml SHALL have a `layer` field.

**Acceptance Criteria**:
- Validation function checks every brick definition for `layer` field
- Missing `layer` field is reported as an error
- Error message identifies which brick(s) are missing the layer field
- Error message explains that layer is a required field per A001

**Rationale**: The layer field is REQUIRED per A001 Section 4. It defines the brick's position in the architectural hierarchy and enables dependency discipline. Flat architecture (all layer 0) is allowed, but the field must be present.

**Valid Example**:
```yaml
bricks:
  - id: B-core-utils
    name: Core Utilities
    layer: 0
    units: [...]
```

**Invalid Example**:
```yaml
bricks:
  - id: B-core-utils
    name: Core Utilities
    # layer field missing!
    units: [...]
```
