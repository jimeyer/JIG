# Configuration File Discovery

JIG discovers configuration files by searching from the current directory upward.

**Acceptance Criteria:**
- Search order: `jig.toml` → `.jig.toml` → `pyproject.toml` (first found wins)
- For `pyproject.toml`, configuration exists only if `[tool.jig]` section is present
- Search stops at filesystem root
- Returns None if no configuration file found (caller uses defaults)
- File access errors produce clear error messages with file path

**Rationale:** Follows Python ecosystem conventions (pyproject.toml) while providing dedicated config file option.

**References:** A003 (Configuration Architecture)
