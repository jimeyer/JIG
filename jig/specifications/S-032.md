# Collapse and Expand Brick Containers

The visualizer MUST allow users to collapse and expand brick containers to hide/show member nodes.

**Acceptance Criteria**:
- Double-clicking a brick container toggles collapse/expand state
- Collapsed bricks hide all member nodes (children invisible)
- Collapsed bricks show member count in label (e.g., "Brick Name (42)")
- Collapsed bricks have distinct styling (more opaque background, badge/indicator)
- Expanded bricks show all member nodes (children visible)
- Expanded bricks show only brick name in label
- "Expand All" button expands all brick containers simultaneously
- "Collapse All" button collapses all brick containers simultaneously
- Collapse state persists when switching layouts (collapsed bricks remain collapsed)
- Layout re-runs after collapse/expand to adjust node positions
- Console logs collapse/expand actions (e.g., "Collapsed brick: B-001")
- No lag or performance issues when toggling state

**Rationale**: Large graphs with many bricks become visually overwhelming. Collapse/expand reduces cognitive load by allowing users to hide implementation details while preserving high-level brick structure.
