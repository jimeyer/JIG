# Filter Nodes by Brick Membership

The visualizer MUST allow users to show/hide entire bricks and their members via checkbox filters.

**Acceptance Criteria**:
- Brick filter checkboxes dynamically populated from loaded intent graph
- Each brick has a checkbox labeled with brick name (e.g., "B-001: JIG Core Decorators")
- All brick checkboxes checked by default (all bricks visible on load)
- Unchecking a brick checkbox hides the brick container AND all member nodes
- Re-checking a brick checkbox shows the brick container AND member nodes
- "All" button checks all brick checkboxes (shows all bricks)
- "None" button unchecks all brick checkboxes (hides all bricks)
- Filter state persists across layout changes
- Brick filters work alongside existing node type filters (classes, functions, modules)
- If a brick is collapsed AND filtered out, it remains collapsed when filter is re-enabled
- Console logs filter changes (e.g., "Brick filter updated: showing N of M bricks")
- No performance lag when toggling filters

**Rationale**: Filtering entire bricks enables focused analysis on specific subsystems or features. Complements collapse/expand for managing visual complexity in large graphs.
