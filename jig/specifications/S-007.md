# Parse NDJSON Implementation Graph Format

The visualizer MUST parse implementation graph NDJSON files into a structured data model.

**Acceptance Criteria**:
- Parse line 1 as metadata object with `_meta` key containing `node_count`, `edge_count`, `version`, `generated`
- Parse lines 2-N as node objects with `id`, `type`, and type-specific fields
- Parse remaining lines as edge objects with `source`, `target`, `type`, and optional fields
- Handle malformed JSON with descriptive error messages including line numbers
- Return structured object with `metadata`, `nodes`, and `edges` arrays

**Rationale**: NDJSON format allows streaming and incremental parsing. Proper parsing is foundational to all visualization features.
