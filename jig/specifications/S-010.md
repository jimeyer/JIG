# Filter Nodes by Type with Real-Time Update

The visualizer MUST allow filtering nodes by type with immediate graph updates.

**Acceptance Criteria**:
- Checkboxes provided for: Classes, Functions, Modules, External Modules
- Unchecking a checkbox immediately hides all nodes of that type
- Re-checking a checkbox immediately shows all nodes of that type
- Filtering preserves graph layout (nodes don't jump around)
- Hidden nodes' edges are also hidden
- Filter state persists during session (doesn't reset on other interactions)

**Rationale**: Large graphs become overwhelming. Filtering by type allows focusing on specific architectural layers (e.g., only classes, only modules) to reduce visual clutter.
