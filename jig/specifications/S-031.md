# Render Bricks as Cytoscape Compound Nodes

The visualizer MUST render bricks as Cytoscape compound nodes with computed parent-child relationships.

**Acceptance Criteria**:
- Create Cytoscape node elements for each brick from intent graph: `{group: 'nodes', data: {id: 'B-001', type: 'brick', name: 'Brick Name', ...}}`
- Assign `parent` field to implementation node elements from computed membership: `{group: 'nodes', data: {id: 'F-func', parent: 'B-001', ...}}`
- Brick nodes render as rectangles with visible borders
- Brick nodes have semi-transparent background (background-opacity < 1)
- Brick labels display at top of container (text-valign: 'top')
- Brick labels use larger, bold font (font-size: 16px, font-weight: bold)
- Member nodes positioned inside brick boundaries by Cytoscape layout engine
- Member nodes styled distinctly (smaller size, normal font weight)
- Compound node structure does NOT modify NDJSON files on disk (parent assignment only in memory)
- Console confirms compound structure created (e.g., "Created N brick nodes with M total members")

**Rationale**: Cytoscape compound nodes provide native grouping and interaction. Parent-child relationships computed at query time maintain A001 compliance while enabling visual clustering.

- Cytoscape compound nodes: https://js.cytoscape.org/#notation/compound-nodes
- A001 §6.2: Implementation graph SHALL NOT contain brick/parent fields
