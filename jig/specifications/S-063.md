# TOML Configuration Parsing

JIG parses configuration files using TOML format with clear error reporting.

**Acceptance Criteria:**
- TOML files are parsed according to TOML 1.0 specification
- For `pyproject.toml`, only the `[tool.jig]` section is extracted
- For `jig.toml` / `.jig.toml`, the `[jig]` section is used (or root if no section)
- Invalid TOML syntax produces error with line number and character position
- Unknown configuration keys produce error with key name and suggestion for typos
- Configuration includes schema `version` field for forward compatibility

**Rationale:** TOML avoids YAML type coercion issues and is the Python ecosystem standard.
