# Test Function Hashing

Test functions have content hashes computed using the same algorithm as implementation functions (S-047).

**Acceptance Criteria:**
- Uses AST-based hashing (same algorithm as S-047)
- Excludes decorators from hash computation
- Normalizes formatting via AST unparse
- Hash changes when test logic changes
- Hash stable across whitespace and comment changes
- Hash stored in `jig_hash` field of test node

**Rationale:** Content hashes enable change detection for audit triggers (J023). Test changes may indicate verification drift.
