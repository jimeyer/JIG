# Display Node Metadata When Selected

The visualizer MUST display detailed node metadata when a node is selected.

**Acceptance Criteria**:
- Clicking a node displays its metadata in the details panel
- For all nodes: show `id`, `type`, `name`
- For code nodes (class/function): show `file`, `line`, `language`
- For classes: show `bases`, `implements` (if present)
- For functions: show `signature`, `parent_class` (if method), `async` flag
- For modules: show `file` (if internal module)
- Metadata display is formatted for readability (not raw JSON)
- Clicking another node updates the panel (doesn't require closing first)

**Rationale**: Nodes are visual abstractions. Developers need access to full metadata (file paths, line numbers, signatures) to understand and navigate to source code.
