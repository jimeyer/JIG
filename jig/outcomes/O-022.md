# Current Data Guarantee for Commands

JIG commands operate on up-to-date graph data without requiring manual rebuild invocation.

**Value:** Developers receive correct results from `validate`, `show`, and `audit` commands
without remembering to run `jigy rebuild` first. Eliminates a class of "stale data" bugs
where developers act on outdated analysis.

**Why This Matters:**
- Stale graphs lead to false confidence: validation passes against old code
- Manual rebuild before every command adds friction and is easily forgotten
- Naive auto-rebuild on every command wastes ~2 seconds when nothing changed
- Smart staleness detection provides correctness without sacrificing speed

**Acceptance Criteria:**
- Commands automatically rebuild only stale graphs before executing
- When nothing changed, staleness check completes in <200ms
- Non-git projects gracefully fall back to always-rebuild behavior
- Users can skip auto-rebuild when needed (`--no-rebuild`)
