# Clear Actionable Error Messages

Validation error messages include file paths, line numbers, and actionable descriptions that enable developers to fix issues without reading documentation.

**Value**: Reduces context switching and documentation lookups. Developers resolve 80%+ of validation issues from error messages alone.

**Acceptance Criteria**:
- All error messages include file path and line number (when applicable)
- Error messages describe what's wrong and imply how to fix it
- Error messages are grouped by validation phase for clarity
- Summary shows total error count for quick assessment
