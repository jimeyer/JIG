# Test-to-Specification Traceability

Tests that verify specifications are discoverable and queryable, completing the S-F-T alignment triangle.

**Value:** Enables queries like "which specs have no verifying tests?" and "which tests verify this spec?" — surfacing verification gaps before they become production issues.

**Acceptance Criteria:**
- T→S edges are captured from `@jig.verifies` decorators
- Test functions have content hashes for change detection
- Verification gaps are visible in `jigy status` output
