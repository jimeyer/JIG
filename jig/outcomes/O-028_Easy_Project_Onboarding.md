# Easy Project Onboarding

New projects can be bootstrapped with a complete, consistent JIG structure through a single command. This removes friction from adoption and ensures all projects start with the correct directory layout, configuration, and optional agent skills.

## Value

- **Reduced onboarding time** - New contributors and projects get working JIG structure immediately
- **Consistency across projects** - All JIG projects share the same structural patterns
- **Agent enablement** - Skills can be installed alongside project structure, enabling AI-assisted development from day one
