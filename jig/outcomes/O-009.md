# Generate Intent Graph from Specifications and Bricks

Developers can generate a complete intent graph containing specifications, outcomes, and brick definitions from human-authored artifacts.

**Value**: Provides a machine-readable representation of project intent (what we want to build) that can be joined with implementation graphs for alignment analysis. Centralizes brick definitions alongside specifications for holistic intent visualization.

**Acceptance Criteria**:
- Intent graph generated from `jig/specifications/*.md`, `jig/outcomes/*.md`, and `jig/bricks.yaml`
- Graph conforms to A001 §6.1 schema (spec nodes, outcome nodes, brick nodes)
- Brick nodes include `units` arrays for query-time joining with implementation graph
- Output in NDJSON format for clean git diffs and streaming processing
- Generation is deterministic and reproducible
