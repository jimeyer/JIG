# Visualize Bricks as Compound Nodes

Developers can see brick boundaries as visual containers around member implementation nodes in the graph visualizer.

**Value**: Makes brick architecture tangible and visible. Helps developers understand which code belongs to which brick without reading YAML files or memorizing boundaries. Reduces cognitive load when reasoning about brick alignment and cohesion.

**Acceptance Criteria**:
- Brick containers render with clear visual boundaries (borders, background)
- Brick names displayed prominently on containers
- Member nodes (functions, classes, modules) positioned inside brick boundaries
- Compound node structure follows Cytoscape conventions for consistency
- Visual distinction between brick nodes and member nodes (size, styling)
- Brick membership computed at query time per A001 §6.2 (no stored parent fields)
