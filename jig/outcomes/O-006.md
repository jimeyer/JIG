# Fast Project Validation

Full project validation completes in under 5 seconds, making it practical to run frequently during development.

**Value**: Fast validation enables integration into pre-commit hooks, CI pipelines, and watch mode workflows. Developers validate often rather than avoiding validation due to slowness.

**Acceptance Criteria**:
- `jigy validate` completes in < 5 seconds on typical projects
- Intent validation (specs, outcomes, decorators) runs without graph generation
- Performance scales reasonably with project size
- Validation speed enables frequent use during development
