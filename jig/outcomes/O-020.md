# Configurable Project Structure

JIG adapts to diverse project layouts without requiring projects to reorganize their code.

**Value:** Enables JIG adoption in existing projects with non-standard directory structures (e.g., `tests/` instead of `test/`, `lib/` instead of `src/`) without forcing disruptive restructuring.

**Acceptance Criteria:**
- Projects with custom directory layouts can use JIG by specifying paths in configuration
- Projects with standard layouts require no configuration
- Configuration is optional, explicit, and version-controlled
